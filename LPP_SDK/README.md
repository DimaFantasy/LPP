# LPP_SDK — основной SDK лазерного принтера

Данная папка содержит **основной SDK проекта LPP-Laser (Linear Path Platform — Laser Edition)**.  
SDK предоставляет общие структуры данных, глобальные переменные и интерфейсы для взаимодействия между модулями прошивки.

## Подключение

Чтобы использовать SDK, необходимо:
1. Подключить заголовочный файл **`lpp_sdk.h`** в основной файл проекта (`main.c` или `main.cpp`).
2. Реализовать все объявленные в SDK функции в своём коде — согласно назначению каждой функции и структуре интерфейса.

## Назначение

SDK служит базовым уровнем взаимодействия между:
- модулями управления движением (ось X/Y, энкодеры, моторы);
- блоком лазера и синхронизации печати;
- интерфейсом USB/настройки/диагностики.

Файлы:
- **`lpp_sdk.h`** — объявления структур, типов и функций;
- **`lpp_sdk.c`** — глобальные переменные и базовая логика SDK.
